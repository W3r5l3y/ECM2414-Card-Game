DESIGN PRODUCTION CODE
----------

Random choice of card removal, so no live-lock.
Player 'hand' volatile.
Deck 'deck' volatile.
drawCard synchronized.
discardCard synchronized.
wait() in deck.isEmpty() loop in drawCard to prevent player from drawing from empty deck. notifyAll() in after discardCard() execution to get waiting threads to check their pack.

--------------------------------------------------
DESIGN TESTS
----------
We chose JUnit 5 for our project because it provides a more modern and flexible framework for writing and running unit tests.
Annotations such as @BeforeEach, @AfterEach, and @DisplayName allow for greater readability and configurability, while Assertions and Assumptions provide more powerful and flexible testing conditions.

Naming for test classes were test[function_name][sub_part_of_function] if multiple test functions were needed for the same function.
